# fixture-ds

The same eleven components as `fixture-rich` (avatar, badge, button, card,
dropdown-menu, input, label, select, separator, table, tabs) and the same
`app/globals.css`, in a project that is not a shadcn project: the
components live in `ds/` and import as `@/ds/button`, there is no
`components.json`, and nothing was generated by the CLI. Used to measure
that the linter's discovery works from `package.json`, the stylesheet,
and an import pattern alone. `eval.json` tells the harness the layout.
